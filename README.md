# Cat Social 🐱

Учебный проект — социальная сеть для котиков. Создан в рамках обучения JavaScript и TypeScript.

## О проекте

Cat Social — это мини-социальная сеть где можно публиковать посты от имени своего котика, ставить лайки и общаться с другими котовладельцами.

## Что реализовано

- Создание постов с текстом, именем котика, аватаркой и фото
- Редактирование и удаление постов через модальные окна
- Лайки с сохранением состояния
- Сортировка постов по дате и количеству лайков
- Фильтрация постов по имени котика
- Сохранение данных в localStorage
- Загрузка тестовых постов с сервера (jsonplaceholder)
- Пагинация — загрузка постов по 10 штук
- Валидация формы через регулярные выражения
- Счётчик символов при написании поста

## Технологии

- TypeScript
- Vite
- CSS (Flexbox, Grid)
- localStorage API
- Fetch API (async/await)

## Архитектурные решения

- Разделение кода на модули (main, render, storage, types, eventBroker)
- Паттерн Observer через EventBroker
- ООП: классы PostCard и FeaturedPostCard с наследованием
- Интерфейсы TypeScript для типизации данных

## Запуск проекта

```bash
npm install
npm run dev
```
